# meow-mess-site

Static English support and legal pages for the Meow Mess game, published with
GitHub Pages. Plain HTML and one CSS file: no frameworks, no scripts, no cookies,
no analytics, no external fonts.

## Pages

| Path | Purpose |
|---|---|
| `index.html` | landing / support page with the link to the policy |
| `privacy/index.html` | Meow Mess Privacy Policy |

## Publishing with GitHub Pages

Repository settings -> **Pages** -> Source: **Deploy from a branch** ->
Branch: `main`, folder `/ (root)` -> Save.

The site is then served at `https://myhighspace-arch.github.io/meow-mess-site/`
and the policy at `https://myhighspace-arch.github.io/meow-mess-site/privacy/`.

## Support address

The public contact address is `morning.musse@gmail.com`; it is used on both
pages. To replace it later with a domain-based address, update every occurrence
of that address in `index.html` and `privacy/index.html`.

## Accuracy

The text states only what is true for the current app: no account, no ads, no
in-app purchases, no analytics or tracking, no personal data collection, offline
play, and a few values kept in local storage on the device. If the app starts
doing anything else with data, this site has to be updated before that release —
Google Play compares the policy with the Data safety form.

## No secrets

This repository holds static HTML and CSS only: no application source code, no
keys, no user data.
